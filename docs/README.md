## Status language

- **Implemented** means the behavior exists in the current code.
- **Partial** means the behavior exists but has a known limitation or incomplete path.
- **Planned** means the document recommends it; the repository does not yet implement it.

These documents are intentionally evidence-based. Product aspirations and hardening recommendations are labeled so they are not mistaken for current behavior.
